# pylopdf-fonts-th

Optional Thai generation fonts for
[pylopdf](https://github.com/yhay81/pylopdf):
Noto Sans Thai and Noto Serif Thai variable fonts.

```bash
pip install "pylopdf[th]"
```

The unmodified files come from
[`google/fonts`](https://github.com/google/fonts) revision
`7ff85c87f93ea6cca5f41c69f2e4edcb90240f26`. Their SHA-256 values are
`5a1c559bb539583c8a1fd99d1c5b9491e5e14478c9cd2bd0970d5c3096cc9ef8`
and `34a7ad11647c845303aabdde639059806c56b84719e5d2ceb28eb038711bdf53`.
Both are licensed under the SIL Open Font License 1.1.
