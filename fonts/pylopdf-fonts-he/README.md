# pylopdf-fonts-he

Optional Hebrew generation fonts for
[pylopdf](https://github.com/yhay81/pylopdf):
Noto Sans Hebrew and Noto Serif Hebrew variable fonts.

```bash
pip install "pylopdf[he]"
```

The unmodified files come from
[`google/fonts`](https://github.com/google/fonts) revision
`7ff85c87f93ea6cca5f41c69f2e4edcb90240f26`. Their SHA-256 values are
`7ef36a2c3593758cdb622e1bdef4f84523e92fbc3ccc667438dd80ff54c2de88`
and `93caef921360788dc3b0e32136bb26f16bc57717ec482d48fc7fd43820617165`.
Both are licensed under the SIL Open Font License 1.1.
