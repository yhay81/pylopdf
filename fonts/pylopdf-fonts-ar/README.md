# pylopdf-fonts-ar

Optional Arabic generation fonts for
[pylopdf](https://github.com/yhay81/pylopdf):
Noto Sans Arabic and Noto Naskh Arabic variable fonts.

```bash
pip install "pylopdf[ar]"
```

The unmodified files come from
[`google/fonts`](https://github.com/google/fonts) revision
`7ff85c87f93ea6cca5f41c69f2e4edcb90240f26`. Their SHA-256 values are
`63111b5b2e074dd48cc67692e0a2726d86ee94c1c37fe8598257b7b4e87e869e`
and `67b5a525a661b607971fbd3f96a81b89d3a768e74534fca84f18ac97e6fab72f`.
Both are licensed under the SIL Open Font License 1.1.
