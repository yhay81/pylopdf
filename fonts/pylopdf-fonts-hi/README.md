# pylopdf-fonts-hi

Optional Devanagari generation fonts for
[pylopdf](https://github.com/yhay81/pylopdf):
Noto Sans Devanagari and Noto Serif Devanagari variable fonts.

```bash
pip install "pylopdf[hi]"
```

The unmodified files come from
[`google/fonts`](https://github.com/google/fonts) revision
`7ff85c87f93ea6cca5f41c69f2e4edcb90240f26`. Their SHA-256 values are
`9ce7b04f60e363d8870e5997744cf85cf69d38a4d7d129d364d92a3b14b461d7`
and `1191e07bfeb062d80e252eb85b0eafdfbda1e350707a2a60628668e8f677dbbb`.
Both are licensed under the SIL Open Font License 1.1.
